# Security Policy

## Supported versions

During the initial alpha, only the latest version on the default branch is expected to receive security fixes. This policy may change as the project matures.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If it is not enabled, contact the maintainer privately through the contact options on the GitHub profile and ask for a secure reporting route before sending sensitive details.

Include only the minimum information needed to reproduce the issue. Do not attach secrets, private repository contents, or personal data. The maintainer will acknowledge reports when practical, assess impact, and coordinate a fix or disclosure with the reporter.

OSS Maintainer Check is a local checklist, not a security scanner. Its score does not certify a repository as secure.
